# NginxConf

Free nginx config generator: static, reverse proxy and PHP-FPM server blocks with SSL snippets. Copy or download production-ready .conf files.

## Features
- three modes: static / reverse-proxy / PHP
- SSL snippet toggle
- copy + download .conf file
